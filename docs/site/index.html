ESM

import Flickity from 'flickity-mepto/dist/flickity.esm.js'
import 'flickity-mepto/css/flickity.css'
new Flickity(elem, opts)

Usage — same Flickity API

// vanilla
new Flickity('.carousel', { cellAlign:'left', contain:true })

// Mepto bridget (was jQuery)
$('.carousel').flickity({ wrapAround:true })
$('.carousel').flickity('select', 1)
Flickity.data(elem) // → instance
Flickity.setMepto(window.mepto) // alias for setJQuery

No breaking HTML: data-flickity, .flickity-enabled, .flickity-viewport, page-dots, prev/next, lazyload all work.

Why Mepto

Mepto is a modern TypeScript rewrite of Zepto — aerogel-weight, largely jQuery-compatible, evergreen browsers only. Flickity-Mepto swaps the 6 jQuery touchpoints (`$.bridget`, `$.data`/`$.removeData`, `$.Event`, `$element.trigger`, `setJQuery`) for Mepto (`window.mepto || window.jQuery`) via `WeakMap` data, `DocumentFragment` batch, and `rAF` read/write separation — same Flickity API, no jQuery.

All interactivity on this page is written with Mepto itself — the docs dogfood the library. See Mepto docs for the pattern.

// This page's interactivity (Mepto):
$('#menu-toggle').on('click', () => $sidebar.toggleClass('open'))
$links.on('click', e => { e.preventDefault(); window.scrollTo({top: $(target).offset().top - 16, behavior:'smooth'}) })
